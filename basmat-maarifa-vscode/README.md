# بصمة معرفة — ملفات التحرير في Visual Studio Code

هذا المجلد يحتوي نسختين:

1. `screens/` — كل شاشة في ملف HTML مستقل ومعها صورة PNG مرجعية تحمل الاسم نفسه.
2. `prototype-integrated/` — النسخة التفاعلية المربوطة التي تحفظ الحالات والإشعارات تجريبيًا في المتصفح.

## تشغيل المشروع

- افتحي المجلد كاملًا في Visual Studio Code.
- لمشاهدة قائمة الشاشات افتحي `index.html` أو شغّليه بإضافة Live Server.
- لتعديل شاشة محددة افتحي ملفها داخل أحد المجلدات:
  - `screens/employee`
  - `screens/reviewer`
  - `screens/manager`
- الصورة الموجودة بجانب كل ملف HTML هي مرجع بصري للشاشة قبل التعديل.
- لتشغيل المسار التفاعلي افتحي `prototype-integrated/index.html`.

## ملاحظة مهمة

ملفات `screens` مستقلة وسهلة التعديل، أما الربط وتغيّر الحالات تلقائيًا فموجود في `prototype-integrated`. بعد اعتماد التعديلات على الشاشات يمكن نقلها إلى النسخة المربوطة.
